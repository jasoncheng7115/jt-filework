2. Keyboard

2. 鍵盤

Two profiles, both plain text files in keymaps/. A binding is a line; adding one rebuilds nothing. The keys you can press right now are named along the foot of the window and change with what the cursor is on.

Typing is typing. The moment the keyboard is in a text field — the path bar, the filter, a rename box, the search box — every letter goes to that field. A single-key command cannot fire out from under someone who is typing, and that holds while a completion list is open too.

打字就是打字。游標在輸入欄位裡的時候（路徑列、篩選框、更名框、搜尋框），每個字母都算那個欄位的。 單鍵命令不會在你打字的時候跳出來，自動完成清單開著也一樣。

Native mode

原生模式

The operating system's own combinations, for when muscle memory says Cmd-C. Switching between the two profiles is one chord, and that chord is the same in both — a switch that only exists in the mode you left is a door that locks behind you.

作業系統自己的組合鍵，給習慣按「Cmd-C」的人。兩套設定檔用一個組合鍵切換，兩邊都是同一個； 只在其中一邊有的開關，等於一扇會在背後鎖上的門。

4. Selection and marks

4. 選取與標記

Selecting a row marks it, and marking a row selects it. They were two separate concepts and are now one, because keeping them apart meant Shift-selecting six files and finding none of them ticked — and then an operation acting on something other than what was highlighted.

選取一列就是標記它，標記一列就是選取它。本來是分開的兩件事，現在合成一件。 分開的結果是：用 Shift 選了六個檔案，一個都沒被勾到，接著操作動到的又不是畫面上亮著的那些。

Tick box勾選框 Adds one row to the set. Clicking a second box does not empty the first 把一列加進去。勾第二個不會把第一個清掉
Clicking a row點一列 Chooses that row, and only that row. This is the one gesture that replaces the set 只選那一列。這是唯一一個會把整組換掉的操作
Space Marks and moves on. Three presses mark three rows 標記並移到下一列。按三次就標記三列
Header box標題列的框 All, none, and a third state when only part of the list is marked 全選、全不選；只標了一部分的時候是第三種狀態
Counting計數 The status line counts rows in the folder on screen. Marks made elsewhere are kept but not counted here, and never acted on by accident 狀態列算的是目前這個資料夾的列。在別的地方標的會留著，不算進來， 也不會被誤動到
Dragging拖曳 Carries what the cursor is on. Dragging an unmarked row does not drag the marked set instead 拖的是游標所在的那一列。拖一個沒標記的，不會連整組標記一起走

Both say when they are showing part of a file rather than pretending to show all of it. The limits are deliberate: the line index is eight bytes per line and building it reads every byte, so an unbounded one meant a multi-gigabyte log froze the window and held hundreds of megabytes before showing a single line.

兩者在只顯示部分內容時都會說出來，不會假裝顯示了全部。這些上限是刻意的： 行索引每行要八個位元組，而且建索引得把整個檔案讀過一遍。沒有上限的話， 開一個好幾 GB 的日誌會讓視窗卡死，第一行還沒畫出來就先吃掉幾百 MB。

Text encodings: detected from the byte-order mark and then from the content, and selectable by hand — UTF-8, UTF-16 LE and BE, Big5, GB18030, Shift-JIS, EUC-KR, Latin-1. Line endings (LF, CRLF, CR) are detected and reported rather than normalised away.

文字編碼：先看位元組順序記號、再看內容自動偵測，也可以自己指定：UTF-8、UTF-16 LE 與 BE、Big5、GB18030、Shift-JIS、EUC-KR、Latin-1。 換行字元（LF、CRLF、CR）會偵測出來並顯示，不會被偷偷統一掉。

Quick Look on macOS is the real system panel, the same one Finder shows. Windows and Linux have no equivalent, so the command is hidden there rather than offered and inert.

快速查看在 macOS 上是真的系統面板，跟 Finder 開的是同一個。 Windows 跟 Linux 沒有對應的東西，所以那兩邊直接把這個命令隱藏，不做按了沒反應的按鈕。

7a. Writing a disk image

7a. 把映像檔寫入磁碟

The most destructive thing this program does. Everything on the chosen disk is gone, with no undo and no trash — so the safety is in which disks are offered, not in the dialog. Enumeration is a whitelist: a disk appears only when the program positively established that it is removable, external and not carrying the running system. A disk whose properties could not be read does not appear.

這是這個程式做的最不可逆的事。選到的那顆磁碟上的東西會全部沒有， 沒得復原也沒有回收筒。所以安全性放在哪些磁碟會被列出來，不是放在對話框。 列表是白名單：程式要能確定那顆是可移除、外接、而且沒裝著現在在跑的系統，才會出現。 資料讀不齊的那顆不會出現。

Sources來源 Any file, byte for byte — .iso, .img, .dmg, a raw dump. Nothing is interpreted, so nothing can be misinterpreted 任何檔案，一個位元組都不改：.iso、.img、 .dmg、原始 dump。內容完全不解讀，所以也不會解讀錯
Offered會列出來的 Removable and external only. Never the boot or system disk. Never an internal disk, even one that is neither. Never a disk of size zero 只有可移除的外接磁碟。開機碟跟系統碟一定不列。內建磁碟一定不列， 就算它兩個都不是也一樣。容量 0 的不列
Refused, and said so擋下來並說原因 A disk too small for the image, and the disk the image itself is sitting on. Both are listed with the reason rather than hidden — a disk you expected to see and cannot is worse than one you can see and are told about 裝不下映像檔的，還有映像檔本身就放在上面的那顆。這兩種會列出來並 寫原因，不會直接藏起來。你以為會看到卻找不到，比看得到但被告知原因更糟
Order順序 Unmount, write, flush, reopen, read back and compare. Unmounting first because a mounted filesystem's driver writes to the same sectors 卸下、寫入、等磁碟寫完、重新開啟、讀回來比對。先卸下是因為掛載中的 檔案系統驅動程式會寫到同一批磁區
Verification核對 On by default, byte for byte, and it is the only thing that catches a failing stick or a counterfeit one — both accept every write and hand back something else. A mismatch reports the byte offset 預設開啟，逐位元組比對。快壞掉的隨身碟跟假的隨身碟都是照單全收、 讀出來卻是別的東西，只有這一步抓得到。對不上會報出是第幾個位元組
Checksum檢查碼 CRC-32 (ISO-HDLC), the same number gzip and cksum -a crc32 print, so it can be compared with a published one by eye CRC-32（ISO-HDLC），跟 gzip、 cksum -a crc32 印出來的是同一個數字，可以直接跟官方公布的用眼睛比
Privilege權限 Borrowed for the one operation. macOS uses authopen, so nothing of ours ever runs as root; Linux uses pkexec, and skips the prompt when the caller already has access; Windows needs an elevated process and says so before it starts 只為了這一次操作跟系統借。macOS 用 authopen， 我們的程式碼完全不會用 root 跑；Linux 用 pkexec，本來就有權限的話不會問； Windows 需要提權的行程，會在開始前先講
Cancelling取消 Stops. The disk then holds part of an image and is not usable, which is what it says — there is nothing to put back 會停。磁碟上就只有映像檔的一部分，不能用，程式會直接這樣講。 沒有東西可以還原
Alignment對齊 The final write is padded with zeros to a whole 512-byte sector, which the raw device requires. The reported length is the image's own 最後一次寫入會補 0 補滿 512 位元組的磁區，raw device 要求這樣。 回報的長度還是映像檔自己的長度

Disc usage磁碟用量 One walk, two answers: which child folder holds the most, and which kind of file adds up to the most. Files sitting in the folder get a row of their own so the rows add up. Copy, move and trash work from inside the report, and it measures again afterwards 掃一次給兩個答案：哪個子資料夾最大，還有哪一類檔案加起來最大。 直接放在那個資料夾裡的檔案自己佔一列，所以每列加起來就是總計。複製、移動、丟回收筒 都可以在報告裡直接做，做完會重新統計

11. Limits and bounds

11. 上限與界線

Every one of these is a real constant in the source, not a guideline. They exist because the input is often something the user did not make — an archive from the internet, a disc image, a session file someone shared — and a reader with no bound is a reader that can be made to exhaust the machine.

下面每一個都是原始碼裡真正的常數，不是建議值。它們存在的原因是：輸入常常不是 使用者自己做的：網路上抓的壓縮檔、映像檔、別人給的工作階段檔。 讀取器要是不設上限，就可以被拿來把機器的資源吃光。

12. What it refuses to do

12. 拒絕的事

A file manager that quietly does something other than what it was asked is worse than one that says no. These are the cases where it says no.

一個偷偷做了別的事的檔案管理器，比一個直接說「不行」的更糟。下面是它會說不行的情況。

A member that would land outside the folder you chose 會落在你所選資料夾之外的成員 Refused and reported — never written, never silently renamed — in every spelling: ../, an absolute path, a Windows drive letter, a UNC prefix, backslashes on any platform 擋下來並回報，不寫、也不會自己改名。不管它怎麼寫都一樣： ../、絕對路徑、Windows 磁碟機代號、UNC 路徑開頭、任何平台上的反斜線
A symlink inside an archive壓縮檔裡的符號連結 Refused, not created. Writing one means a later write through it lands wherever the archive chose 擋下來，不建立。建了它，之後寫進去的東西會跑到壓縮檔說了算的地方
A symlink during a walk走訪時遇到的符號連結 Never followed — not when searching, measuring, comparing, analysing or deleting. A link is a name, not a door 一律不跟進去，搜尋、計算、比較、分析、刪除都一樣。連結是一個名字，不是一扇門
A directory swapped mid-delete刪除中途被掉包的資料夾 Cannot lead the delete out of the selection: the walk holds an open directory descriptor and never resolves a path twice 帶不出你選的範圍。走訪的時候拿著開啟的目錄描述符，路徑不會再被解析第二次
A session file from a newer build較新版本寫的工作階段檔 Refused, and left exactly as it is. This build writes beside it, never over it 擋下來，原檔原封不動。這一版會寫在它旁邊，不會蓋掉
Any removal任何刪除 Confirmed first, every time, from every route. Permanent deletion says it cannot be undone before it runs 每次都先確認，不管從哪裡發動。永久刪除會在執行前說明無法復原
A conflict名稱衝突 Reported with the first conflicting name and a choice. Never resolved by guessing 會回報第一個撞名的並讓你選。不會自己決定
