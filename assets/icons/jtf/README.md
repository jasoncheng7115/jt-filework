# jt-filework icons

Drawn for this project, for shapes the vendored Iconoir set does not have.
Same conventions as Iconoir so the two sit together without looking mixed:
24×24 viewBox, `stroke-width="1.5"`, `fill="none"`, and every stroke
`currentColor` so `glyph::make` can tint them.

These are ours. Iconoir's licence covers `../iconoir` only.
